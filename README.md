# ru_text

ロシア語検定(ТРКИ)3級→2級の間にある語彙ギャップを埋めるための教科書プロジェクトの、
語彙選定パイプラインを管理するリポジトリ。

## 現在の方針

1. 「日常生活・時事・娯楽・一般教養」に絞ったトピック集(`data/topics/`)を元に、
   常に「啓蒙的・平易な文体」で大量の文章を生成する(専門的すぎるトピックや
   堅い文体はCEFRの想定を超える語彙を持ち込むことが分かっているため避ける)。
2. 生成した文章から `scripts/extract_vocabulary_stanza.py` で語彙を抽出・レンマ化する。
3. 抽出した各語のCEFRレベルは、Claudeの教育的判断による一次推定で割り当てる。
4. 最終的な採否はユーザー自身による手動レビュー(ブラックリスト作業)で確定する。

## ディレクトリ構成

- `data/topics/` — 文章生成用のトピック集
- `scripts/` — 語彙抽出用のスクリプト

## 実行環境についての注意

`scripts/extract_vocabulary_stanza.py` は Stanza(PyTorchベース、未知語耐性が高い)を
使う。ロシア語モデルはHuggingFace経由でのみ配布されているため、HuggingFaceへの
アクセスが制限された環境では実行できない。モデルは `~/.cache/stanza/` に
キャッシュされるため、CI環境で実行する場合は `actions/cache` での永続化を推奨する。
